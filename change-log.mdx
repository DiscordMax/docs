# v1.9.0
### v1.9.5
__[UPDATE] TICKET TRANSCRIPTS:__
- We've been working diligently behind the scenes to upgrade our transcripts system. Previously, as most know, transcript links—like Discord attachment links—would expire after two weeks. This often led to frustration when users tried to access important proof or conversations, only to find them gone. Now, all transcript files will be uploaded securely to Report Bot itself. You’ll be able to access them anytime through permanent links at [tickets.reportbot.xyz/](https://tickets.reportbot.xyz/).  No more expired links—just reliable, long-term access to every ticket.

__[NEW] MORE TRANSLATIONS:__ 
- Report Bot now supports multiple languages! You can configure your server’s language, and all bot messages will be translated accordingly. In addition to bot messages being translated, command names and descriptions are localized. Commands and Apps will appear in the language you have configured on Discord.
  - Report Bot now supports the following languages: Italian, Danish, German, Dutch, Korean, and Japanese in addition to our previously announced languages.
- Find a translation that is not correct? Submit a fix request here: [Form Link](https://forms.gle/9Pk9ELsSgY1joiNd7) 

__Fixes__
- Fixed undefined value(s) in the case closed embed if you press the close button on the `/ticket request-close` embed.
- Fixed an issue where the "Case ID not found" embed would not appear and would cause an error if you used the `/case` command.

### v1.4.0
**[NEW]** __TICKETS__:
- Tickets are a whole new way to do reports. Users can create report tickets within your server to talk directly with server moderators. Tickets help make sure the reports you make have the up most detail. Yes, there are transcripts. 😉
  - Get started with Tickets in your server by using `/config tickets`

**[NEW]** __Case Create__:
-  How do you take action against a user reported in a ticket? Use the `/case create` command. This command requires you have the Case ID which will be shown on the ticket creation embed. It also requires you provide a user. After you have filled out that information you will get a reply with a familiar panel. You can punish multiple users for the same case ID.

# v1.0.0
What's new? Everything.

**Report Bot**
- `/report`
  - Report a user for violating server rules.
- `/lookup user`
  - Look up any completed cases on a user.
- `/lookup case-id
  - View more information on a case using the unique case ID.

**AutoMod**
- `/automod flags`
  - Block content from your server.
- `/automod keyword`
  - Block keywords from your server.
- `/automod mention-spam`
  - Prevent mention spam.
- `/automod message-spam`
  - Prevent mention spam.

**Configuration**
- `/config report-log`
  - Configure the channel reports will go to.
- `/config action-log`
  - Configure the channel actions will be logged in.
- `/config moderator`
  - Configure a moderator role that can handle reports. Note: Server Administrators can bypass this.

**Miscellaneous** 
- `/whois`
  - View user information.
- `/ping`
  - View the bot's ping
- `/invite`
  - Learn how to invite the bot or join the support server.
- `/help`
  - View all the bot's commands.
- `/botinfo`
  - View the bot's information.
